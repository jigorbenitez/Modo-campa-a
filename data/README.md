# Datos territoriales

Estructura de ingreso para datasets públicos. Cada municipio tiene una carpeta
independiente y debe documentar fuente, licencia, fecha de descarga, CRS y nivel
de confianza antes de importar.

Los archivos aceptados son GeoJSON, Shapefile comprimido, GeoPackage y CSV. Los
datos aceptados y optimizados para la aplicación se publican en `src/data`; los
originales nunca se sobrescriben.
