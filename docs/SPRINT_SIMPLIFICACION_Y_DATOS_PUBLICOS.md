# ATIY — Simplificación y datos públicos

## Navegación

El menú queda reducido a Dashboard, Centro Operativo, Recorridas, Territorio, Inteligencia, Relaciones, Agenda y Administración. Las rutas existentes permanecen compatibles, pero dejan de competir en la navegación principal.

En móvil se muestran cuatro accesos principales y un panel “Más” con los cuatro restantes. El comando global se abre con `Ctrl+K`/`Cmd+K` o con el botón flotante móvil.

## Integración

- Territorio concentra listado, búsqueda, filtros por categoría y estado, creación, edición, eliminación, importación y exportación.
- Administración reúne usuarios, roles, permisos, auditoría, logs de sesión, respaldos, intercambio de datos y configuración.
- La barra contextual mantiene a San Fernando como raíz y agrega módulo, localidad/barrio, circuito o entidad cuando existen parámetros territoriales.

## Datos

Los datos nuevos se documentan en `FUENTES_PUBLICAS_SAN_FERNANDO.md`. No se completaron categorías con coordenadas aproximadas. Los registros importados por usuarios ingresan como pendientes de revisión.

## Compatibilidad

No se eliminaron rutas ni entidades del dominio. Presupuesto, propuestas, vecinos, configuración y demás superficies siguen accesibles mediante relaciones, acciones contextuales o enlaces internos. La simplificación afecta la arquitectura de información, no la capacidad existente.
